# 组会 / 汇报 PPT 文案学术语域（速查）

> 完整替换表与校对清单见 `research-writing-skill/references/academic-presentation-language.md`。本文件只列汇报场景最常用规则。

## 规则

- **标题 = 一句完整学术陈述**：主语（研究对象/方法）+ 谓语 + 限定/结论，可带量化证据（数字、复杂度、对比对象）。
- 禁止口语与口号：讲透、听懂、干货、踩坑、搞定、算不动、不是摆设、对我有用、换时间、硬扛、掉坑、"……就够了/就行"、"专门测……"。
- 动词精确化并给比较基准：提升 / 降至 / 增加 / 保持稳定 / 显著 / 略有；不用"快 / 慢 / 崩 / 涨 / 掉到"。
- 数字带单位与基准；希腊字母与符号（θ、φ、m、n、O(m)、N_ik）首次出现给释义。
- 每页一个观点；结论行用"证据 → 结论"；图注含来源（Fig.N 论文原图 / Table N 按原文重绘）。
- 页面文字一律书面语；演讲备注是口播稿，可自然口语化。

## 高频替换（示例）

| 口语/口号 | 规范表达 |
| --- | --- |
| 五个模块，把一篇论文讲透 | 汇报框架：按五个模块系统展开论文解读 |
| 三个前置概念，听懂后面所有公式 | 三个前置概念：理解本文方法所需的基础知识 |
| A 算不动、E 精度崩 | 方法 A 无法求解、方法 E 精度显著下降 |
| 拟合公式不是摆设 | 验证拟合公式的必要性 |
| 对我最有用的两件事 | 本文方法对后续研究的两点启示 |
| 精度比 XX 高一截 / 快一个数量级 | 精度较 XX 高 0.1 个百分点 / 效率提升约一个数量级 |

## 提交前检查

- 逐标题对照上表与完整替换表；
- 数字是否有单位与基准；是否残留感叹号、反问、拟人；
- 术语缩写全文一致且首次出现有释义；
- 图注与来源（Fig./Table 编号）齐全；
- 只做语言修订时，公式、数值、结构不得被改动。
